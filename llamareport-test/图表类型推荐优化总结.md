# 图表类型推荐优化总结

## 问题描述

用户反馈生成的所有视图都是折线图，希望优化图表类型推荐逻辑，让系统能够根据数据特征生成不同类型的图表（折线图、柱状图、饼图等），包括复杂视图。

## 问题分析

### 原有问题

1. **推荐逻辑过于简单**：
   - `time_series` 总是推荐 `LINE`
   - `comparison` 总是推荐 `BAR`
   - `distribution` 总是推荐 `PIE`
   - 没有考虑数据点数量、多系列等特征

2. **优先级问题**：
   - 问题类型推荐优先于数据类型推荐
   - 导致某些情况下推荐不准确

3. **缺少复杂视图支持**：
   - 没有考虑多系列数据（应使用 `MULTI_LINE` 或 `GROUPED_BAR`）
   - 没有考虑数据点数量对图表类型的影响

## 优化方案

### 1. 基于数据特征的智能推荐（优先级最高）

**文件：** `backend/agents/visualization_agent.py`

**优化内容：**

#### 1.1 分布类型（distribution）
- **数据点 ≤ 8**：推荐 `PIE`（饼图）
- **数据点 > 8**：推荐 `BAR`（柱状图，避免饼图过于拥挤）

#### 1.2 对比类型（comparison）
- **有多个系列**：推荐 `GROUPED_BAR`（分组柱状图）
- **数据点 ≤ 5**：推荐 `BAR`（柱状图）
- **数据点 > 5**：推荐 `BAR`（柱状图）

#### 1.3 时间序列类型（time_series）
- **有多个系列**：推荐 `MULTI_LINE`（多折线图）
- **数据点 ≤ 10**：
  - 如果问题类型是 `comparison`：推荐 `BAR`（柱状图）
  - 否则：推荐 `LINE`（折线图）
- **数据点 > 10**：推荐 `LINE`（折线图）

#### 1.4 其他类型
- **single_value**：推荐 `GAUGE`（仪表盘）
- **table**：推荐 `TABLE`（表格）
- **risk_matrix**：推荐 `SCATTER`（散点图）

#### 1.5 未知类型推断
- **单一数据点**：推荐 `GAUGE`
- **百分比数据（0-100）且数据点 ≤ 8**：推荐 `PIE`
- **有多个系列**：推荐 `GROUPED_BAR`
- **其他**：推荐 `BAR`

### 2. 基于问题类型的推荐（作为备选）

**优化内容：**

- **structure（结构类）**：
  - 如果数据类型是 `distribution`：优先 `PIE`
  - 否则：优先 `BAR`

- **conclusion（结论类）**：
  - 如果单一数据点：优先 `GAUGE`
  - 如果数据类型是 `distribution`：优先 `PIE`
  - 否则：使用第一个推荐类型

- **comparison（对比类）**：
  - 优先 `BAR`

- **data（数据类）**：
  - 根据数据类型选择：`time_series` → `LINE`，`comparison` → `BAR`，`distribution` → `PIE`

### 3. 综合推荐策略

**优先级：**
1. **数据类型推荐**（最高优先级）
2. **问题类型推荐**（作为备选）
3. **特殊情况处理**：
   - `distribution` + `structure` → 优先 `PIE`
   - `time_series` + `comparison` → 优先 `BAR`

### 4. 推荐理由优化

**优化内容：**

- 添加数据类型说明（如"时间序列数据"、"对比数据"等）
- 添加数据特征说明（数据点数量、是否多系列）
- 添加图表类型说明（为什么推荐这种图表）
- 添加问题类型说明（如果有）

**示例：**
```
时间序列数据；5个数据点；折线图适合展示趋势变化；问题类型：数据类：折线图、柱状图、KPI指标卡
```

### 5. 备选图表优化

**优化内容：**

- 根据推荐类型添加相关备选：
  - `LINE` → `AREA`, `BAR`, `MULTI_LINE`
  - `BAR` → `LINE`, `GROUPED_BAR`, `STACKED_BAR`
  - `PIE` → `BAR`, `FUNNEL`, `STACKED_BAR`
  - `GAUGE` → `BAR`, `PIE`
  - `SCATTER` → `HEATMAP`, `BAR`
  - `MULTI_LINE` → `GROUPED_BAR`, `LINE`, `AREA`
  - `GROUPED_BAR` → `MULTI_LINE`, `STACKED_BAR`, `BAR`

- 结合问题类型和数据类型的备选

### 6. 数据提取 Prompt 优化

**优化内容：**

- 添加数据类型判断规则说明
- 明确各种数据类型的特征
- 在多个数据集的示例中，为每个数据集指定正确的 `data_type`

## 修改位置

### 文件：`backend/agents/visualization_agent.py`

1. **`_recommend_chart_type()` 方法**（第1113-1320行）
   - 重写了推荐逻辑
   - 添加了基于数据特征的智能推荐
   - 优化了推荐理由生成
   - 优化了备选图表生成

2. **`_extract_data_from_answer()` 方法**（第470-530行）
   - 优化了数据提取 prompt
   - 添加了数据类型判断规则说明

## 效果

### 优化前
- 所有 `time_series` 数据都推荐 `LINE`
- 所有 `comparison` 数据都推荐 `BAR`
- 所有 `distribution` 数据都推荐 `PIE`
- 没有考虑数据点数量、多系列等特征

### 优化后
- **分布数据（≤8个数据点）**：推荐 `PIE`
- **分布数据（>8个数据点）**：推荐 `BAR`
- **对比数据（多系列）**：推荐 `GROUPED_BAR`
- **时间序列（多系列）**：推荐 `MULTI_LINE`
- **时间序列（少量数据点 + comparison问题）**：推荐 `BAR`
- **时间序列（较多数据点）**：推荐 `LINE`
- **单一指标**：推荐 `GAUGE`
- **风险矩阵**：推荐 `SCATTER`

## 注意事项

1. **数据点数量**：数据点数量会影响图表类型选择（如饼图不适合太多数据点）
2. **多系列数据**：检测到多个系列时，应使用多折线图或分组柱状图
3. **问题类型**：问题类型会影响推荐（如 `comparison` 问题即使有时间维度也可能推荐柱状图）
4. **向后兼容**：保留了原有的回退逻辑，确保在出错时仍能推荐合适的图表

## 总结

优化后的图表推荐逻辑：
- ✅ 根据数据特征智能推荐（数据点数量、多系列等）
- ✅ 支持多种图表类型（折线图、柱状图、饼图、仪表盘、散点图等）
- ✅ 支持复杂视图（多折线图、分组柱状图、堆叠柱状图等）
- ✅ 提供详细的推荐理由
- ✅ 提供相关备选图表

现在系统能够根据数据特征智能推荐合适的图表类型，不再总是推荐折线图。
