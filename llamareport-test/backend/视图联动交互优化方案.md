# 视图联动交互优化方案

## 📋 优化目标

在现有界面基础上，优化以下三个方面的交互体验：
1. **视图卡片选择方式**：更直观、更便捷
2. **下钻问题输入方式**：更自然、更智能
3. **新视图和洞察展示**：更清晰、更有层次

---

## 🎨 优化方案一：卡片选择优化

### 当前问题
- 需要先点击"选择卡片"按钮进入选择模式
- 选择模式切换不够直观
- 选中的卡片视觉反馈不够明显

### 优化方案：直接选择 + 浮动操作栏

#### 1. 卡片直接选择（无需切换模式）

**设计**：
- 移除"选择卡片"按钮
- 卡片默认支持直接点击选择
- 选中的卡片显示明显的选中状态

**交互**：
```
鼠标悬停卡片
    ↓
显示选择提示："点击选择此卡片"
    ↓
点击卡片
    ├─ 未选中 → 选中（显示✓标记）
    └─ 已选中 → 取消选中
    ↓
选中后显示浮动操作栏
```

#### 2. 浮动操作栏（Floating Action Bar）

**位置**：当有卡片被选中时，在卡片列表底部或顶部显示

**设计**：
```vue
<!-- 浮动操作栏 -->
<div v-if="selectedCards.length > 0" class="floating-action-bar">
  <div class="action-bar-content">
    <!-- 选中卡片信息 -->

      <span class="selected-count">已选择 {{ selectedCards.length }} 个视图</span>
      <button class="clear-selection-btn" @click="clearSelection">清除选择</button>

```

## 🎨 优化方案二：下钻问题输入优化

### 当前问题
- 需要展开输入框，增加操作步骤
- 输入框位置可能遮挡内容

### 优化方案：智能输入 + 上下文提示

#### 1. 内联输入（在浮动操作栏中）

**设计**：
- 探索问题输入直接集成在浮动操作栏中
- 支持回车键快速生成
- 实时显示输入状态

#### 2. 智能提示（基于选中卡片）

**功能**：
- 根据选中的卡片，自动推荐相关问题
- 显示在输入框下方，可点击快速填充

**实现**：
```javascript
// 根据选中卡片生成推荐问题
computed: {
  recommendedQuestions() {
    const selected = this.selectedCards
    if (selected.length === 0) return []
    
    const questions = []
    
    // 单卡片推荐
    if (selected.length === 1) {
      const card = selected[0]
      const title = card.question || ''
      
      if (title.includes('营收') || title.includes('收入')) {
        questions.push('营收增长的主要原因是什么？')
        questions.push('营收趋势未来如何？')
      }
      if (title.includes('利润') || title.includes('ROE')) {
        questions.push('利润变化的主要原因是什么？')
        questions.push('ROE下降的原因是什么？')
      }
      if (title.includes('资产') || title.includes('负债')) {
        questions.push('资产结构如何？')
        questions.push('负债率是否合理？')
      }
    }
    
    // 多卡片推荐
    if (selected.length > 1) {
      questions.push('这些指标之间有什么关联？')
      questions.push('这些视图反映了什么趋势？')
      questions.push('哪些因素影响了这些指标？')
    }
    
    return questions.slice(0, 3)  // 最多显示3个
  }
}
```

#### 3. 输入增强

**功能**：
- 自动完成：输入时显示相关建议
- 问题模板：提供常见问题模板
- 历史记录：显示最近使用的问题（可选）

## 🎨 优化方案三：新视图和洞察展示优化

### 设计理念

**核心思想**：一个视图卡片 = 视图 + 洞察（一体化展示）

每个新生成的视图卡片都包含：
1. **视图部分**：LLM生成的图表/可视化
2. **洞察部分**：该视图相关的洞察和分析
3. **元信息**：视图类型、数据质量、关联关系等

### 优化方案：一体化视图卡片

#### 1. 视图卡片结构设计

**数据结构**：

```javascript
  },
  insight: {

    confidence: "high" | "medium" | "low",
    evidence_chain: [...]

  data_quality: "high" | "medium" | "low",
  related_cards: ["card_id1", "card_id2"],
  showRelated: false  // UI状态

```

**处理逻辑**：
```javascript
// 将后端返回的数据转换为卡片格式
function transformLinkageResponseToCards(response) {
  const cards = []
  
  // 处理新生成的视图
  if (response.new_views && response.new_views.length > 0) {
    response.new_views.forEach((view, index) => {
      const card = {
        id: view.view_id || `linkage_${Date.now()}_${index}`,
        type: 'chart',
        view_type: view.view_type,
        title: view.description || `视图 ${index + 1}`,
        description: view.description,
        exploration_question: response.exploration_question,
        data: view.visualization || {},
        insight: this.extractInsightFromView(view, response.synthesis_insight),
        data_quality: view.data_quality || 'unknown',
        related_cards: view.related_cards || [],
        showRelated: false,
        isLinkageGenerated: true,  // 标记为联动生成
        timestamp: new Date()
      }
      cards.push(card)
    })
  }
  
  // 如果有综合洞察但没有视图，创建一个洞察卡片
  if (response.synthesis_insight && cards.length === 0) {
    const insightCard = {
      id: `insight_${Date.now()}`,
      type: 'insight',
      view_type: 'comprehensive',
      title: '综合洞察',
      description: '基于选中视图的综合分析',
      exploration_question: response.exploration_question,
      data: {
        has_visualization: false
      },
      insight: response.synthesis_insight,
      isLinkageGenerated: true,
      timestamp: new Date()
    }
    cards.push(insightCard)
  }
  
  return cards
}

// 从视图和综合洞察中提取洞察信息
function extractInsightFromView(view, synthesisInsight) {
  // 优先使用视图特定的洞察
  if (view.insight) {
    return view.insight
  }
  
  // 如果没有，使用综合洞察
  if (synthesisInsight) {
    return {
      conclusion: synthesisInsight.conclusion,
      key_findings: synthesisInsight.key_findings || [],
      confidence: synthesisInsight.confidence || 'medium'
    }
  }
  
  return null
}
```
