# 卡片选择深入探索功能设计方案

## 📋 功能概述

**功能名称**：卡片选择 + 深入探索问题

**核心价值**：
- ✅ 用户可以选择多个卡片后，输入一个探索问题来指导视图联动方向
- ✅ 让用户更精确地控制想要深入探索的方向
- ✅ 提升视图联动的针对性和相关性

**使用场景**：
- 用户选择了"营业收入趋势图"和"净利润趋势图"后，输入"为什么营收增长但利润下降？"
- 用户选择了"ROE分析"后，输入"ROE下降的主要原因是什么？"
- 用户选择了多个财务指标卡片后，输入"这些指标之间有什么关联？"

---

## 🎯 功能目标

1. **增强用户控制**：让用户能够明确表达探索意图
2. **提升联动质量**：基于用户问题生成更相关的视图
3. **改善用户体验**：提供更自然的交互方式
4. **保持灵活性**：问题可选，不强制用户输入

---

## 🏗️ 整体架构设计

### 1. 交互流程

```
用户选择卡片（1个或多个）
    ↓
显示"生成总分析"按钮
    ↓
点击"生成总分析"按钮
    ↓
展开探索问题输入区域
    ├─ 提示："请输入您想要深入探索的问题（可选，不输入则进行综合分析）"
    ├─ 输入框：支持多行文本
    └─ 示例提示（可点击快速填充）：
       - "为什么营收增长但利润下降？"
       - "这些指标之间有什么关联？"
       - "ROE下降的主要原因是什么？"
    ↓
用户选择：
    ├─ 输入问题 → 点击"生成分析" → 聚焦回答用户问题
    └─ 不输入问题 → 点击"生成分析" → 综合分析
    ↓
后端接收：选中的卡片 + 探索问题（可能为空）
    ↓
视图联动引擎处理
    ├─ 如果有探索问题：聚焦回答用户问题（focused模式）
    └─ 如果没有探索问题：进行综合分析（comprehensive模式）
    ↓
生成新视图和洞察
```

## 📊 使用场景示例

### 场景1：因果关系探索

**用户操作**：
1. 选择卡片："营业收入趋势图"、"净利润趋势图"
2. 输入探索问题："为什么营收增长但利润下降？"

**系统处理**：
1. 识别问题类型：`why`（为什么）
2. 聚焦领域：盈利能力、成本结构
3. 推荐视图类型：解释型（因果路径图）
4. 生成视图：
   - 解释型：营收→成本→利润的因果路径图
   - 验证型：成本结构拆分图
   - 验证型：毛利率、净利率对比图

### 场景2：关联关系探索

**用户操作**：
1. 选择卡片："ROE分析"、"资产周转率"、"净利润率"
2. 输入探索问题："这些指标之间有什么关联？"

**系统处理**：
1. 识别问题类型：`relationship`（关系）
2. 聚焦领域：杜邦分析、指标关联
3. 推荐视图类型：解释型（关联网络图）
4. 生成视图：
   - 解释型：ROE分解关联图
   - 验证型：各指标时间序列对比图

### 场景3：趋势预测探索

**用户操作**：
1. 选择卡片："营业收入趋势图"、"净利润趋势图"
2. 输入探索问题："未来趋势如何？"

**系统处理**：
1. 识别问题类型：`trend`（趋势）
2. 聚焦领域：趋势分析、预测
3. 推荐视图类型：导航型（趋势标注图）
4. 生成视图：

## ⚠️ 注意事项

### 1. 用户体验
- **输入框位置**：应该明显但不遮挡主要内容
- **提示信息**：清晰说明"不输入则进行综合分析"
- **示例问题**：提供有代表性的示例，可点击快速填充
- **按钮文本**：动态显示"生成分析（聚焦问题）"或"生成分析（综合分析）"

### 2. 性能考虑
- **问题长度限制**：建议限制在200字符以内
- **LLM调用**：探索问题会增加一次LLM调用，需要考虑性能
- **超时处理**：如果分析时间过长，提供降级方案

### 3. 错误处理
- **空问题处理**：如果用户输入了空白问题，应该忽略
- **问题过长**：如果问题过长，提示用户缩短
- **分析失败**：如果探索问题分析失败，降级到默认逻辑

### 4. 数据验证
- **问题格式**：验证问题是否合理（非空、非纯符号等）
- **问题相关性**：检查问题是否与选中卡片相关（可选）
