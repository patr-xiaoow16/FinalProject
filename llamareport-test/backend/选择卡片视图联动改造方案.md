# 选择卡片视图联动改造方案

## 📋 改造概述

**目标**：将现有的"选择卡片生成综合能力分析"功能改造为基于视图联动方案的智能视图生成功能。

**核心原则**：
- ✅ **前端交互不变**：保持选择卡片、点击"生成总分析"的交互方式
- ✅ **后端逻辑升级**：使用视图联动方案的LLM驱动方式
- ✅ **功能增强**：从单一雷达图升级为多视图网络（验证型、解释型、导航型）

---

## 🔄 现有功能分析

### 当前实现

**前端**：
- 用户选择多个可视化卡片
- 点击"生成总分析"按钮
- 调用 `/query/comprehensive-analysis` 接口
- 返回一个雷达图卡片

**后端**：
- 从选中的卡片中提取指标（ROE、营业收入等）
- 生成4个维度的综合能力分析（盈利能力、运营能力、成长能力、现金能力）
- 生成雷达图配置
- 返回单一雷达图

**限制**：
- ❌ 只能生成单一类型的视图（雷达图）
- ❌ 没有分析卡片之间的关系
- ❌ 没有生成验证型、解释型、导航型视图
- ❌ 没有数据验证机制

## 🎯 改造方案

### 1. 整体架构

```
用户选择多个卡片
    ↓
前端：点击"生成总分析"按钮（交互不变）
    ↓
后端：接收选中卡片列表
    ↓
视图联动引擎（LLM驱动）🤖
    ├─ 阶段一：多卡片分析
    │   ├─ 提取每个卡片的视图摘要
    │   ├─ LLM分析卡片之间的关系
    │   └─ LLM识别关键洞察点
    ├─ 阶段二：联动分析（LLM执行）
    │   ├─ 对齐分析：卡片之间的数据对齐
    │   ├─ 综合推理：生成综合洞察
    │   └─ 数据需求分析：分析需要什么数据
    ├─ 阶段三：数据检索与验证
    │   ├─ 检索相关数据
    │   └─ 验证数据可用性
    └─ 阶段四：新视图生成（LLM驱动）🤖
        ├─ 生成验证型视图
        ├─ 生成解释型视图
        └─ 生成导航型视图
    ↓
返回多个新视图卡片
```

## 🔧 核心功能模块

### 1. 多卡片分析引擎（MultiCardAnalysisEngine）

**位置**：`agents/view_linkage.py`

**功能**：
- 提取每个选中卡片的视图摘要
- 使用LLM分析多个卡片之间的关系
- 识别关键洞察点和数据缺口

**实现思路**：
```python
class MultiCardAnalysisEngine:
    def __init__(self, llm=None):
        self.llm = llm or Settings.llm
        self.chart_summary_generator = ChartSummaryGenerator()
    
    async def analyze_multiple_cards(
        self,
        selected_cards: List[Dict[str, Any]],
        context_filter: Optional[Dict] = None
    ) -> Dict[str, Any]:
        """
        分析多个卡片之间的关系
        
        流程：
        1. 提取每个卡片的视图摘要
        2. 使用LLM分析卡片之间的关系
        3. 识别关键洞察点和数据缺口
        """
        # 1. 提取视图摘要
        card_summaries = []
        for card in selected_cards:
            if card.get('data') and card['data'].get('has_visualization'):
                summary = self.chart_summary_generator.generate_summary(
                    card['data'].get('chart_config')
                )
                summary.view_id = card.get('id')
                summary.original_question = card.get('question', '')
                card_summaries.append(summary)
        
        # 2. 使用LLM分析卡片关系
        analysis = await self._analyze_card_relationships(card_summaries)
        
        return {
            "card_summaries": card_summaries,
            "card_relationships": analysis["relationships"],
            "key_insights": analysis["insights"],
            "data_gaps": analysis["gaps"]
        }
    
    async def _analyze_card_relationships(
        self,
        card_summaries: List[ChartSummary]
    ) -> Dict[str, Any]:
        """
        使用LLM分析卡片之间的关系
        """
        prompt = self._build_card_relationship_prompt(card_summaries)
        response = await self._call_llm(prompt)
        return self._parse_llm_response(response)
    
    def _build_card_relationship_prompt(
        self,
        card_summaries: List[ChartSummary]
    ) -> str:
        """
        构建卡片关系分析的Prompt
        """
        cards_info = []
        for i, summary in enumerate(card_summaries, 1):
            cards_info.append(f"""
### 卡片{i}
- ID: {summary.view_id}
- 问题: {summary.original_question}
- 视图类型: {summary.chart_type.value}
- 视图标题: {summary.title}
- 关键指标: {', '.join(summary.key_metrics)}
- 时间范围: {summary.time_range}
- 数据模式:
  - 趋势: {summary.patterns.get('trend', '未知')}
  - 拐点: {summary.patterns.get('turning_points', [])}
""")
        
        return f"""
你是一个专业的财务分析专家，擅长分析多个视图之间的关系。

## 任务
分析以下{len(card_summaries)}个视图卡片之间的关系，识别关键洞察和数据缺口。

## 视图卡片信息

{''.join(cards_info)}

## 分析任务

1. **关系分析**：
   - 这些视图之间是互补关系、冲突关系还是支持关系？
   - 哪些视图可以相互验证？
   - 哪些视图之间存在因果关系？

2. **关键洞察**：
   - 从这些视图的组合中，能得出什么综合洞察？
   - 有哪些重要的发现？

3. **数据缺口**：
   - 要验证这些洞察，还缺少什么数据？
   - 需要生成哪些新视图来补充？

## 输出格式（JSON）

{{
    "relationships": [
        {{
            "card1_index": 0,
            "card2_index": 1,
            "relationship_type": "complementary/supporting/conflicting",
            "description": "关系描述",
            "confidence": "high/medium/low"
        }}
    ],
    "insights": [
        "洞察1：...",
        "洞察2：..."
    ],
    "gaps": [
        "缺少数据1：...",
        "缺少数据2：..."
    ],
    "recommended_views": [
        {{
            "view_type": "verify/explain/navigate/comprehensive",
            "description": "视图描述",
            "reason": "为什么需要这个视图",
            "related_cards": [0, 1]  // 关联的卡片索引
        }}
    ]
}}
"""
```

### 2. 多卡片联动生成引擎（MultiCardLinkageEngine）

**位置**：`agents/view_linkage.py`

**功能**：
- 整合多卡片分析和视图联动分析
- 使用LLM生成综合洞察和新视图推荐

**实现思路**：
```python
class MultiCardLinkageEngine:
    def __init__(self, llm=None):
        self.llm = llm or Settings.llm
        self.multi_card_analyzer = MultiCardAnalysisEngine(llm)
        self.linkage_engine = LinkageGenerationEngine(llm)
        self.view_generator = NewViewGenerator(...)
    
    async def generate_linkage_from_cards(
        self,
        selected_cards: List[Dict[str, Any]],
        company_name: str,
        year: str,
        context_filter: Optional[Dict] = None
    ) -> MultiCardLinkageResponse:
        """
        从选中的卡片生成视图联动
        
        流程：
        1. 分析多个卡片之间的关系
        2. 对关键卡片进行联动分析
        3. 生成新视图
        """
        # 1. 多卡片分析
        card_analysis = await self.multi_card_analyzer.analyze_multiple_cards(
            selected_cards, context_filter
        )
        
        # 2. 选择关键卡片进行深度联动分析
        # 优先选择有互补关系或支持关系的卡片对
        key_card_pairs = self._select_key_card_pairs(
            card_analysis["card_relationships"]
        )
        
        # 3. 对每个关键卡片对进行联动分析
        linkage_results = []
        for card1_summary, card2_summary in key_card_pairs:
            # 使用LinkageGenerationEngine进行联动分析
            linkage = await self.linkage_engine.generate_linkage_analysis(
                chart_summary=card1_summary,
                original_query=card1_summary.original_question,
                original_answer=f"基于视图：{card1_summary.title}",
                related_text=f"相关视图：{card2_summary.title}\n{card2_summary.original_question}"
            )
            linkage_results.append({
                "source_cards": [card1_summary.view_id, card2_summary.view_id],
                "linkage_analysis": linkage
            })
        
        # 4. 生成综合洞察（基于所有卡片）
        synthesis_insight = await self._generate_comprehensive_insight(
            card_analysis, linkage_results
        )
        
        # 5. 生成新视图
        new_views = await self._generate_views_from_linkage(
            linkage_results, card_analysis, company_name, year
        )
        
        return MultiCardLinkageResponse(
            source_cards=[card.get('id') for card in selected_cards],
            card_analysis=card_analysis,
            synthesis_insight=synthesis_insight,
            new_views=new_views,
            view_network=self._build_view_network(selected_cards, new_views)
        )
    
    def _select_key_card_pairs(
        self,
        relationships: List[Dict]
    ) -> List[Tuple[ChartSummary, ChartSummary]]:
        """
        选择关键卡片对进行深度联动分析
        
        策略：
        1. 优先选择互补关系和支持关系的卡片对
        2. 避免选择冲突关系的卡片对（除非需要解释冲突）
        3. 限制数量（最多3对）
        """
        # 过滤出互补和支持关系
        key_relationships = [
            r for r in relationships 
            if r["relationship_type"] in ["complementary", "supporting"]
        ]
        
        # 按置信度排序
        key_relationships.sort(
            key=lambda x: {"high": 3, "medium": 2, "low": 1}.get(x.get("confidence", "low"), 1),
            reverse=True
        )
        
        # 返回前3对
        return key_relationships[:3]
    
    async def _generate_comprehensive_insight(
        self,
        card_analysis: Dict[str, Any],
        linkage_results: List[Dict]
    ) -> Dict[str, Any]:
        """
        生成综合洞察（基于所有卡片和联动分析）
        """
        prompt = f"""
你是一个专业的财务分析专家。基于以下多卡片分析和联动分析结果，生成综合洞察。

## 多卡片分析结果
卡片关系：{json.dumps(card_analysis.get('card_relationships', []), ensure_ascii=False)}
关键洞察：{card_analysis.get('key_insights', [])}
数据缺口：{card_analysis.get('data_gaps', [])}

## 联动分析结果
{json.dumps([r['linkage_analysis'] for r in linkage_results], ensure_ascii=False, indent=2)}

## 任务
生成综合洞察，包括：
1. 一句话综合结论（不超过80字）
2. 证据链（整合所有卡片的证据）
3. 置信度评估
4. 关键发现（5-8条）

## 输出格式（JSON）
{{
    "conclusion": "综合结论",
    "evidence_chain": [
        {{"source": "card/view", "content": "...", "supports": "..."}}
    ],
    "confidence": "high/medium/low",
    "confidence_reason": "原因",
    "key_findings": ["发现1", "发现2", ...]
}}
"""
        response = await self._call_llm(prompt)
        return self._parse_llm_response(response)
```

### 3. API接口改造

#### 3.1 改造现有接口

**端点**：`POST /query/comprehensive-analysis`（保持不变，向后兼容）

**改造策略**：
- 保留原有接口，但内部逻辑改为视图联动方式
- 如果只选中1个卡片，使用单卡片联动
- 如果选中多个卡片，使用多卡片联动

**实现**：
```python
@router.post("/comprehensive-analysis")
async def generate_comprehensive_analysis(request: ComprehensiveAnalysisRequest):
    """
    生成综合视图分析（基于视图联动方案）
    
    支持两种模式：
    1. 单卡片模式：选中1个卡片，生成关联视图
    2. 多卡片模式：选中多个卡片，生成综合分析和关联视图
    
    Returns:
        包含新视图列表的响应
    """
    try:
        logger.info(f"收到综合视图分析请求，选中{len(request.selected_cards)}个卡片")
        
        # 获取RAG引擎
        rag_engine = get_rag_engine()
        if not rag_engine.query_engine:
            if not rag_engine.load_existing_index():
                raise HTTPException(
                    status_code=400,
                    detail="索引未构建，请先处理文档"
                )
        
        # 从context_filter中提取公司名和年份
        company_name = None
        year = None
        if request.context_filter:
            # 尝试从文件名中提取
            filename = request.context_filter.get('filename', '')
            # 解析文件名，提取公司名和年份
            company_name, year = extract_company_and_year_from_filename(filename)
        
        # 如果没有，尝试从overview_data中获取
        if not company_name and request.overview_data:
            company_name = request.overview_data.get('company_name')
            year = request.overview_data.get('year')
        
        # 如果还是没有，使用默认值或从卡片中提取
        if not company_name:
            company_name = "未知公司"
        if not year:
            year = "2024"  # 默认年份
        
        # 根据卡片数量选择处理方式
        if len(request.selected_cards) == 1:
            # 单卡片模式：使用单卡片视图联动
            from agents.view_linkage import SingleCardLinkageEngine
            linkage_engine = SingleCardLinkageEngine(
                query_engine=rag_engine.query_engine,
                rag_engine=rag_engine
            )
            
            card = request.selected_cards[0]
            result = await linkage_engine.generate_linkage_from_card(
                card=card,
                company_name=company_name,
                year=year,
                context_filter=request.context_filter
            )
        else:
            # 多卡片模式：使用多卡片视图联动
            from agents.view_linkage import MultiCardLinkageEngine
            linkage_engine = MultiCardLinkageEngine(
                query_engine=rag_engine.query_engine,
                rag_engine=rag_engine
            )
            
            result = await linkage_engine.generate_linkage_from_cards(
                selected_cards=request.selected_cards,
                company_name=company_name,
                year=year,
                context_filter=request.context_filter
            )
        
        # 构建响应（兼容原有格式，同时支持新格式）
        return JSONResponse(
            status_code=200,
            content={
                "status": "success",
                "linkage_result": result.dict() if hasattr(result, 'dict') else result,
                # 兼容原有格式：如果只有一个视图，可以作为visualization返回
                "visualization": result.new_views[0].visualization_response.dict() 
                    if len(result.new_views) == 1 else None,
                "new_views": [
                    {
                        "view_id": view.view_id,
                        "view_type": view.view_type,
                        "visualization": view.visualization_response.dict(),
                        "description": view.description,
                        "data_quality": view.data_validation.get("data_quality")
                    }
                    for view in result.new_views
                ],
                "synthesis_insight": result.synthesis_insight,
                "card_analysis": result.card_analysis if hasattr(result, 'card_analysis') else None
            }
        )
        
    except HTTPException:
        raise
    except Exception as e:
        logger.error(f"生成综合视图分析失败: {str(e)}")
        import traceback
        logger.error(f"详细错误: {traceback.format_exc()}")
        raise HTTPException(
            status_code=500,
            detail=f"生成综合视图分析失败: {str(e)}"
        )
```

## ⚠️ 注意事项

### 1. 性能考虑

- **LLM调用次数**：多卡片联动可能需要多次LLM调用
  - 优化：合并调用，一次LLM调用完成多卡片分析
  - 限制：最多分析3对关键卡片对

- **响应时间**：可能比原有功能慢
  - 优化：异步处理，显示加载状态
  - 降级：超时后返回部分结果

### 2. 用户体验

- **加载提示**：显示"正在分析卡片关系..." → "正在生成视图..."
- **结果展示**：清晰标识每个视图的类型和用途
- **错误处理**：如果联动失败，提供降级方案

### 3. 数据质量

- **数据验证**：每个新视图都要验证数据
- **质量标记**：明确显示数据质量
- **缺失提示**：数据不足时提供友好提示
